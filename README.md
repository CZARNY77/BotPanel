# ConqBot Panel

Web control panel for **ConqBot**, a Discord bot for Conqueror's Blade guilds.
Part of **ConqApps**: the bot, this panel and the guild website exchange data
(event sign-ups, voice attendance, battle lineups, roles, recruitment, stats).

Live: [conqbot-panel.blcdev.com](https://conqbot-panel.blcdev.com) · Author: [Jakub Wojdyła](https://blcdev.com)

## Stack

React · TypeScript · Vite · Docker / nginx

## Run locally

```bash
npm install
npm run dev
```
